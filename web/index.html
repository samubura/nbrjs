NbrJS

Aggregate computing in JavaScript. Un programma per tutta la rete, dal browser a Puck.js ed ESP32.

Inizia il corso Playground GitHub

Un programma, tutta la rete

Ogni dispositivo esegue la stessa funzione, a round, scambiando messaggi solo con i vicini. Queste due righe calcolano in quanti salti ogni nodo raggiunge la sorgente più vicina:

Clicca un nodo per renderlo sorgente, trascinalo, modifica il codice: la rete si riadatta da sola.

Perché NbrJS

Gli operatori che conosci

nbr, rep, share, branch, xc, con la semantica dell'eXchange Calculus di ScaFi, FCPP e Collektive.

Fatto per l'embedded

Circa 3 KB minificato, eseguito dalla flash. Su Bluetooth un gradiente occupa 3 byte per messaggio.

Stesso codice ovunque

Simulatore nel browser, Node, Puck.js ed ESP32: cambia solo il target nella configurazione.

Dal browser alla scheda

Carichi il programma via Bluetooth o USB direttamente dal playground, senza IDE.

Come si usa

Sui dispositivi, con Espruino: scrivi il programma, poi scegli dove gira.

require('nbrjs').globals();

var hops = (src) => share(Infinity, (d) => src ? 0 : d.min() + 1);
var program = () => hops(sense('source'));

start(program, {
  target: 'ble',          // 'udp' per il WiFi dell'ESP32, 'sim' per simulare
  period: 1000,
  sensors: () => ({ source: BTN1.read() }),
  onResult: (h) => LED1.write(h === 0)
});

Nel playground, Sul dispositivo ↗ installa la libreria sulla scheda e carica il programma. Per l'ESP32 c'è una guida passo passo; con un solo Puck.js puoi provare la demo con il PC.

Nel browser bastano due script, src/core.js e src/sim.js; in Node, require('nbrjs').
