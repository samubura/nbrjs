NbrJS su ESP32

Dalla scheda appena tolta dalla scatola a più ESP32 che calcolano insieme, via Bluetooth o WiFi.

Cosa serve

  • Una o più schede ESP32 classiche, per esempio ESP32-WROOM DevKit. Il firmware Espruino per ESP32 è pensato per questo chip; C3 e S3 non sono coperti dalla documentazione ufficiale.
  • Un cavo USB dati, non solo di ricarica.
  • Chrome o Edge, per caricare il firmware e i programmi dal browser.

1. Installa Espruino

L'ESP32 esce di fabbrica senza Espruino: va installato una volta.

  1. Scarica il firmware per ESP32 dalla pagina download di Espruino: contiene bootloader.bin, partitions_espruino.bin ed espruino_esp32.bin.
  2. Collega la scheda e caricali con lo strumento online di Espruino, oppure da terminale con esptool:
esptool.py --chip esp32 --port /dev/ttyUSB0 --baud 921600 --after hard_reset \
  write_flash -z --flash_mode dio --flash_freq 40m --flash_size detect \
  0x1000 bootloader.bin 0x8000 partitions_espruino.bin 0x10000 espruino_esp32.bin

Su Windows la porta è del tipo COM3, su macOS /dev/cu.usbserial-…. Per gli aggiornamenti successivi basta 0x10000 espruino_esp32.bin.

2. Scegli la rete

Gli ESP32 possono parlarsi via Bluetooth o via WiFi. ESP-NOW, il protocollo diretto di Espressif, in Espruino non è disponibile.

Bluetooth: target: 'ble'

Niente router: ogni scheda sente quelle vicine, come i Puck.js, con cui può stare nella stessa rete. Messaggi fino a 23 byte. Il segnale (nbrSense('rssi')) dice quanto è vicino ogni vicino.

WiFi: target: 'udp'

Le schede si collegano allo stesso access point e si parlano in broadcast. Nessun limite pratico sui messaggi, e anche un PC con Node può entrare nella rete. Però tutte le schede connesse sono vicine fra loro.

Spegni la radio che non usi: libera molta memoria per i tuoi programmi. Il comando riavvia la scheda e cancella il programma salvato.

ESP32.enableWifi(false);   // se usi il Bluetooth: circa 3900 variabili in più
ESP32.enableBLE(false);    // se usi il WiFi: circa 1800 variabili in più

3. Carica il programma

Apri il playground, scrivi o scegli un programma e premi Sul dispositivo ↗:

  1. scegli Bluetooth o WiFi; per il WiFi inserisci nome e password della rete;
  2. spunta Salva se vuoi che il programma riparta a ogni accensione;
  3. Carica via USB e scegli la porta della scheda.

La prima volta la pagina installa la libreria nella flash della scheda, poi carica il programma. Ripeti per ogni ESP32.

Ecco il file che finisce sulla scheda con il WiFi; il pulsante BOOT è BTN1 e il LED integrato LED1, ma sulle schede compatibili possono cambiare:

require('nbrjs').globals();

var program = () => share(Infinity, (d) => sense('source') ? 0 : d.min() + 1);

start(program, {
  target: 'udp',
  wifi: { ssid: 'NomeRete', password: '...' },
  period: 1000,
  sensors: () => ({ source: BTN1.read() }),
  onResult: (h, id) => { LED1.write(h === 0); console.log(id, h); }
});

Con l'Espruino Web IDE

Se preferisci l'IDE di Espruino:

  1. in Settings → Communications imposta il Baud Rate a 115200: l'ESP32 non usa il valore predefinito;
  2. nello stesso pannello aggiungi a Module URL, separato da |, l'indirizzo dei moduli che trovi nella finestra Sul dispositivo del playground;
  3. incolla il file nell'editor e premi Upload.

Se qualcosa non va

  • La scheda non compare fra le porte: prova un altro cavo; alcune schede vogliono il driver CP210x o CH340.
  • Errori WiFi o riavvii: spesso è l'alimentazione. Una porta USB scarsa o un regolatore debole non bastano quando il WiFi trasmette.
  • Le schede non si vedono via WiFi: alcuni router isolano i client o filtrano il broadcast. Prova un hotspot, o una delle schede come access point.
  • "message is N bytes" in console: via Bluetooth il messaggio non sta nei 23 byte. Riduci gli operatori o usa interi piccoli, oppure passa al WiFi.
