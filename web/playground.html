Playground

program.js is the aggregate program, the same code that goes on a device. config.js describes the simulated network: nodes, layout, sensors. Every change restarts the network. To device ↗ uploads the program to a Puck.js or an ESP32.

Quick reference

Operators: xc, retsend, nbr, rep, share, branch, align, id(), sense(name) (in the simulator source, obstacle, x, y and those from config.js), nbrSense('range').

Fields: .self, .map((v, id) => ...), .zip(other, (a, b) => ...), .reduce(f, initial), .min(), .max(), .sum(), .at(id). Reductions skip the device itself.

Library: hopsTo, distanceTo, broadcast, collectSum, isLeader, networkMax, networkMin, neighbourCount, rounds, countdown, minId.

if, ?:, && and || around aggregate code are aligned automatically, like branch.
