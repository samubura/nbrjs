2 · Vicini e campi

Con nbr(v) ogni nodo manda v ai vicini e riceve il loro.

Un valore per ogni vicino

nbr(v) restituisce un campo di vicinato (field): un valore per ogni vicino, più il proprio in .self. Non è un numero, quindi va ridotto a un valore locale:

  • .sum(), .min(), .max(): le riduzioni più comuni;
  • .reduce((acc, v) => ..., iniziale): come Array.reduce, e accetta direttamente Math.min o Math.max.

Le riduzioni escludono il nodo stesso: si sommano solo i vicini. Ecco il numero di vicini di ogni nodo; trascina i nodi o cambia range.

Passa sopra un nodo: manda {"x0":[1]}. x0 è il nome di quel nbr nel programma, e i nodi confrontano solo valori con lo stesso nome. Ne riparliamo nel capitolo 5.

Trasformare e combinare campi

  • .map((v, id) => ...) trasforma ogni valore;
  • .zip(altro, (a, b) => ...) combina due campi valore per valore;
  • nbrSense('range') è un campo dato dal sistema: la distanza da ogni vicino.

Prova tu

1. Il massimo id fra i vicini (gli id del simulatore sono stringhe: usa +id()).

2. "Sono un leader locale?": true se il mio id è maggiore di quello di tutti i vicini.

3. La posizione x media dei vicini (sensore sense('x')).

Soluzioni 
var program = () => nbr(+id()).max();

var program = () => nbr(+id()).max() < +id();

var program = () => nbr(sense('x')).sum() / nbr(1).sum();

Il leader locale funziona anche per nodi isolati: .max() di un campo vuoto è -Infinity.
