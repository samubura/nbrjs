4 · Comporre funzioni

Una funzione aggregata è una normale funzione JavaScript: la passi, la componi, la riusi.

Broadcast: diffondere un valore

Il gradiente dice quanto sei lontano dalla sorgente. Se insieme alla distanza condividiamo un valore, ogni nodo impara anche cosa dice la sorgente più vicina. Il valore condiviso è una coppia [distanza, valore]: un semplice array, perché su Espruino non c'è destructuring.

I colori sono uno per valore distinto: ogni regione è "di proprietà" di una sorgente. Aggiungi sorgenti e guarda le regioni riorganizzarsi.

Blocchi che usano blocchi

Dato broadcast, molte cose diventano una riga. Per esempio la distanza fra due nodi speciali, nota a tutta la rete: il nodo B calcola la sua distanza da A con un gradiente e poi la diffonde.

Trascina il nodo 35 o la sorgente: tutta la rete aggiorna il valore. Ogni chiamata (gradient, broadcast) ha la sua voce nei messaggi (x0, x1), quindi due blocchi non si confondono.

Prova tu

1. Diffondi dalla sorgente il suo contatore dei round (rep): i nodi lontani vedranno numeri più vecchi. Di quanto, rispetto alla distanza?

2. Scrivi hopBroadcast(src, v) che usa i salti invece di range.

Soluzioni 
var program = () => {
  var clock = rep(0, (c) => c + 1);
  return clock - broadcast(sense('source'), clock)[1];  // ritardo: circa i salti dalla sorgente
};

var hopBroadcast = (src, v) => share([Infinity, v], (n) => src ? [0, v] :
  n.map((p) => [p[0] + 1, p[1]]).reduce((best, p) => p[0] < best[0] ? p : best, [Infinity, null]));
